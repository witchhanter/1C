«JSON»
1. «Визитная карточка»
Создайте JSON-файл card.json, который содержит информацию о вас:
"Имя" (строка)
"Возраст" (число)
"Хобби" (строка)
Задача: Используйте потоковую запись (ЗаписьJson) в файл. Сформируйте объект с этими
тремя полями. После записи прочитайте файл и выведите его содержимое в консоль.

2. «Список покупок»
Вам нужно сохранить список покупок в формате JSON.
Задача: Создайте массив строк: ["Хлеб", "Молоко", "Яблоки", "Печенье"]. Запишите этот массив
в файл shopping.json с помощью ЗаписьJson. Затем прочитайте файл и выведите каждый
элемент списка в консоль.

3. «Чтение расписания из JSON»
Дан файл schedule.json с содержимым:
json
{
"Понедельник": "Математика",
"Вторник": "Физика",
"Среда": "Литература",
"Четверг": "История",
"Пятница": "Информатика"
}
Задача: Прочитайте файл, используя объектную технику (СериализацияJson.ПрочитатьОбъект ).
Получите соответствие. Выведите все дни и соответствующие предметы в консоль в
формате: «В Понедельник – Математика».

4. «Запись оценок в JSON»
У вас есть массив оценок: [5, 4, 5, 3, 4].
Задача: Сериализуйте массив в JSON-строку (без записи в файл) с
помощью СериализацияJson.ЗаписатьОбъект() (перегруженный метод для строки). Выведите
получившуюся JSON-строку в консоль. Затем десериализуйте её обратно в массив чисел и
выведите сумму оценок.

5. «Настройки приложения»
Вы разрабатываете приложение, и его настройки нужно сохранять в JSON-файл.
Настройки содержат:
"Темная тема" – истина/ложь,
"Уровень громкости" – число от 0 до 100,
"Имя пользователя" – строка.
Задача: Создайте соответствие с этими настройками. Запишите его в файл settings.json с
отступом в два пробела (по умолчанию) и переносами строк. Затем прочитайте файл и
выведите значение громкости.

6. «Студенческая группа»
В JSON-файле group.json хранится массив студентов, каждый из которых является
объектом:
json
[
{ "Фамилия": "Иванов", "Имя": "Петр" },
{ "Фамилия": "Петрова", "Имя": "Анна" }
]
Задача: Прочитайте файл в массив соответствий с
помощью СериализацияJson.ПрочитатьМассив() . Для каждого студента выведите «Иванов
Петр». Затем добавьте в этот массив (в памяти) ещё одного студента: { "Фамилия": "Сидоров",
"Имя": "Николай" } и перезапишите файл (сериализуйте обратно).

7. «Компактный JSON»
Ваша программа отправляет JSON на сервер, который требует, чтобы JSON был записан в
одну строку без лишних пробелов.
Задача: Создайте объект с полями: "Товар" : "Ноутбук", "Цена" : 50000, "Вналичии" : Истина.
Используя настройки ЗаписьJson (НастройкиЗаписиJson.ПереносСтрок =
ПереносСтрокJson.Отсутствует), запишите этот объект в строку (через строковый поток).
Выведите результат в консоль.

8. «Игровая статистика»
У вас есть файл score.json с массивом результатов игроков:
json
[
{ "Ник": "Мастер", "Очки": 1200 },
{ "Ник": "Новичок", "Очки": 450 },
{ "Ник": "Лидер", "Очки": 2000 }
]
Задача: Прочитайте файл, найдите игрока с максимальным количеством очков и выведите
его ник. Используйте объектную технику для чтения всего массива.

9. «Проверка структуры при записи»
Вы формируете JSON, но случайно забыли закрыть массив.
Задача: Напишите скрипт, который пытается записать следующий некорректный JSON:
начал массив, записал одно число, но не вызвал ЗаписатьКонецМассива. Оберните код
в попытка и перехватите исключение ИсключениеЗаписиJson. Выведите сообщение «Ошибка
структуры JSON». Затем исправьте код, добавив правильное закрытие массива.

10. «Каталог книг» (комплексная задача)
Создайте структуру Книга с полями Название, Автор , Год. Заполните массив из трёх книг
(например, любые). Сериализуйте массив в JSON-файл books.json. Затем прочитайте этот
файл обратно в массив соответствий и выведите все книги, у которых год издания больше
2000.
Указание: При чтении используйте СериализацияJson.ПрочитатьМассив(), получите массив
соответствий. Для каждого соответствия получите значение по ключу "Год" и сравните.
