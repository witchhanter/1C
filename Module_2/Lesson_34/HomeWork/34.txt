«XML»
1. «Запись телефонного справочника»
Задача: Создайте XML-файл phonebook.xml с корневым элементом ТелефоннаяКнига. Внутри
создайте два элемента Контакт, каждый из которых содержит Имя, Номер и Город (для
примера: «Анна», «555-1234», «Москва» и т.д.). Используйте потоковую запись
(ЗаписьXml). Выведите в консоль сообщение «Файл создан».

2. «Чтение контактов»
Задача: Прочитайте файл contacts.xml . Для каждого элемента Контакт выведите в консоль
информацию в формате: «Имя: Иван Петров, Телефон: +7(999)123-45-67,
Email: ivan@example.com». Используйте цикл пока Чтение.Следующий() и проверяйте имя
элемента.

3. «Поиск контакта по имени»
Задача: Напишите программу, которая запрашивает у пользователя имя (например,
«Мария Сидорова») и ищет его в файле contacts.xml. Если найдено, вывести телефон и email.
Если нет – сообщить «Контакт не найден». Используйте потоковое чтение.

4. «Добавление атрибута "тип" к контактам»
Задача: Усовершенствуйте файл contacts.xml, добавив каждому
элементу Контакт атрибут тип со значением «друг» или «работа». Для этого сначала
прочитайте весь файл, затем перезапишите его с новыми атрибутами. Используйте
объектную технику (СериализацияXml), если знаете, или потоковую (создайте новый файл).
Выведите обновлённый XML в консоль.

5. «Каталог книг» (запись)
Задача: Самостоятельно создайте XML-файл new_books.xml с корневым
элементом МоиКниги. Запишите в него три книги (придумайте названия, авторов и год
издания) с помощью ЗаписьXml. Используйте элементы Книга, Название, Автор, Год.

6. «Подсчёт книг»
Задача: Прочитайте файл books.xml. Подсчитайте количество элементов Книга. Выведите на
экран число найденных книг и список всех названий книг с авторами.

7. «Вывод товаров с отступами»
Задача: Прочитайте файл products.xml и выведите его содержимое в консоль с
синтаксическими отступами, как показано в теоретическом примере. Каждый вложенный
элемент должен сдвигаться на 2 пробела. Также выводите атрибуты товаров.

8. «Поиск товара по атрибуту id»
Задача: Пользователь вводит id товара (например, «p002»). Найдите в products.xml товар с
таким атрибутом и выведите его наименование и цену. Используйте потоковое чтение и
проверку атрибутов.

9. «Смешанная техника: десериализация книги»
Задача: Используя смешанную технику (последовательное чтение до элемента Книга,
затем Чтение.ПрочитатьСодержимое() и преобразование в соответствие), обработайте
файл books.xml. Для каждой книги выведите её название и год издания в виде: «Война и
мир (1869)».

10. «Сериализация соответствия в XML»
Задача: Создайте соответствие Товар с ключами "Наименование" и "Цена". Заполните его
данными из объекта {"Наименование":"Смартфон","Цена":20000}.
Используя СериализацияXml.ЗаписатьОбъект() , запишите этот объект в файл item.xml (как
корневой элемент). Выведите содержимое файла в консоль.

11. «Десериализация XML в соответствие»
Задача: Файл products.xml прочитайте с помощью СериализацияXml.ПрочитатьОбъект() (он
вернёт соответствие). Из полученного соответствия извлеките массив товаров и выведите
список всех товаров, у которых цена больше 1000 рублей.

12. «Запись с отключением форматирования»
Задача: Сформируйте XML-документ с элементом Запрос и текстом "Hello world".
Используйте НастройкиЗаписиXml, чтобы отключить переносы строк и отступы
(свойства ПереносСтрок, СимволыОтступа). Результат выведите в консоль как строку
(используйте СтроковыйПотокЗаписи).

13. «Чтение с пространством имён»
Задача: Создайте XML-файл namespace.xml с корневым элементом <root
xmlns="http://example.org/ns"> и дочерним <data>text</data>. Прочитайте его,
используя ЧтениеXml с настройками, игнорирующими пространства имён. Выведите имя
корневого элемента и текст дочернего элемента.

14. «Модификация: добавление нового контакта»
Задача: Добавьте в файл contacts.xml новый контакт (например, «Олег Кузнецов», телефон
+7(999)111-22-33, email oleg@example.com). Для этого прочитайте существующий XML в
память (объектная техника), добавьте новый элемент в массив, затем перезапишите файл.

15. «Обработка ошибок структуры»
Задача: Напишите код, который пытается записать XML с нарушением структуры:
например, после ЗаписатьНачалоЭлемента не вызывает ЗаписатьКонецЭлемента. Оберните запись
в попытка и перехватите ИсключениеЗаписиXml. Выведите сообщение «Ошибка структуры
XML». Затем исправьте код.
